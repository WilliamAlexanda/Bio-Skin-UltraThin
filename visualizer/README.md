# 触觉传感器可视化

> 完整的中英双语说明见 / Full bilingual guide: [VISUALIZER_GUIDE.md](../docs/VISUALIZER_GUIDE.md)

在 PCB 示意图上实时显示 32 个压阻触点的压力，并用一个从 U3（MLX90393）出发的箭头显示剪切力方向。

## 启动
- 在 Finder 里双击 `run.command`，或者在终端运行：
  ```
  cd visualizer
  ./run.command            # 接开发板
  ./run.command --demo     # 演示模式，不需要硬件
  ```
- 在窗口右上角选择串口（`/dev/cu.usbserial-…` 排在最前面），点“连接”。
- **用之前先关掉 VS Code 的串口监视器**，同一个串口一次只能被一个程序打开。

## 数据通路
连接后，程序会给固件发送 `b`，固件随后以 100 Hz 发送二进制数据包（每包 87 字节，格式见 `tactile_sensor/main/main.c` 里的 `stream_pkt_t`）。断开时程序会发送 `t`，固件恢复成文本输出。开发板每次复位后都回到文本模式，所以 VS Code 监视器照常可用。

如果板子上的固件还是旧版本，程序会自动改为解析文本输出（5 Hz）。这时状态栏显示“文本模式（固件未更新？）”，重新烧录 `tactile_sensor` 即可。

## 数据文本
点击右上角的“显示数据文本”，PCB 下方会出现一个文字面板，每秒刷新 10 次。面板依次显示 MLX90393 的 X/Y/Z/T 和相对零点的 dX/dY/dZ（没有 MLX 时显示 N.A.），以及 MUX1、MUX2 各 16 路的 ADC 值。面板使用等宽字体，每个字段的列宽固定，数值变长或变短时位置都不会跳。再点一次按钮可以隐藏面板，开关状态会自动保存。

## 压力颜色
ADC ≥ “无压阈值”（默认 4050）显示为淡黄色；数值越往下掉，颜色依次渐变为绿色、橘色、红色。ADC ≤ “满压 ADC”（默认 1000）时为全红。这两个阈值都可以在右侧面板调整。鼠标悬停在触点上，可以看到它对应的 MUX 通道。

触点编号对应关系：红色编号 1–16 对应 MUX1 的 CH0–15，17–32 对应 MUX2 的 CH0–15（`tactile_viz.py` 里的 `CHANNEL_MAP`）。

## 剪切力箭头和自动归零
- 箭头表示磁场相对“原点”的 X/Y 变化（dX, dY），长度达到“箭头满量程”时为最长。变化小于“死区”时不画箭头。
- **自动归零**：当 U3 周围的 15、16、17、18 四个触点都 ≥ 无压阈值，并且持续 0.15 s 以上时，把最近 0.3 s 磁场的平均值设为新原点，箭头回到中心。此时 U3 周围的虚线框是绿色，状态显示“无接触 · 已归零”。只要其中任何一个触点受压，原点就被冻结（虚线框变橘色），箭头开始显示剪切力。
- 点“手动归零”或按 `Z` 键，可以立即把当前磁场设为原点。
- **方向校准（推荐）**：点击剪切力面板里的“方向校准…”，按提示操作，大约 20 秒：
  1. 松开传感器，记录零点。
  2. 垂直按下再松开 2～3 次。程序据此测出“只按压时 dX/dY 跟着 dZ 一起变”的串扰系数 kx、ky，之后会从剪切信号里扣掉。
  3. 分别朝右、上、左、下推（以界面上 PCB 图的方向为准）。程序据此拟合一个 2×2 矩阵，可以同时修正任意的安装角度、X/Y 两个轴的灵敏度差异以及轴不垂直的问题。

  完成后会显示校准前后的方向误差，点“保存并使用”生效，结果保存在 `viz_config.json`。校准生效后，“箭头旋转 / 翻转”设置不再起作用；点“清除校准”可以恢复使用这两项设置。
- 没做方向校准时，箭头方向要用实物确认：朝一个已知方向推，如果箭头方向不对，就在“箭头旋转 / 翻转 X / 翻转 Y”里调整。设置会自动保存到 `viz_config.json`。

## 不带 MLX90393 的版本
固件检测不到 MLX90393 时（每秒会重试一次），文本输出里 MLX 那一行全部显示 `N.A.`，二进制包里 MLX 有效标志为 0、数值为 NaN。可视化程序会在 U3 位置显示 `N.A.` 和 shear not available，剪切力面板显示“剪切力 not available”。压阻触点的显示和带磁传感器的版本完全一样。
